# Nexus Core // Stealth AI Workspace

A high-tech, full-stack personal AI application designed for advanced document analysis, homework assistance, and highly-variable text generation. Features a futuristic dark-mode UI and customizable text generation style controls to bypass standard detection parameters and simulate natural human writing.

## Core Features
- **Stealth Generation Controls:** Adjust Creativity (Temperature), Structure Variance (Top_p), and Tone (Conversational/Analytical/Creative) to mimic natural human cadence and bypass standard AI detection.
- **Document Ingestion:** Upload `.txt`, `.pdf`, and `.md` files for the AI to read, interpret, and accurately answer complex problems about.
- **High-Tech Interface:** Cyber-themed, responsive dark-mode dashboard with real-time status indicators and a sleek terminal-style output.
- **Local & Private:** Run the workspace directly from your own machine for ultimate privacy and control.
